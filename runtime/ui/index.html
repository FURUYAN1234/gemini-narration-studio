03 / SCRIPT REVIEW

声・ピッチの変更は「02 声・話し方」で行えます。

字幕と読みを一文ずつ対比して修正できます。確認後は末尾の「全文の読みを確定」一回で進めます。各カットの確定ボタンは、そこだけ先に確定したい場合の任意操作です。

各カットに絵と画面見本、字幕、ひらがなの読み、作成済みの音声をまとめています。直接編集・画像差し替えはAPIを使いません。AIへの修正指示と画像の再生成は、対象のカットから実行できます。
