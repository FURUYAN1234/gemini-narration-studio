03 / SCRIPT REVIEW

全文のナレーションを確かめる

0 / 0 確認済み

英字・数字・漢字を確認候補として表示します。読みの正解を自動判定した結果ではありません。読み上げ文を整え、「全文の読みを確定（制作前）」でまとめて確定できます。

声・ピッチの変更は「02 声・話し方」で行えます。

最初に取り込んだ台本を使っています。再読み込みは不要です。字幕と読みを一文ずつ対比して修正できます。

全カットを順番に見直してください。画像・字幕・ひらがなの読み・音声を並べています。気になる点は各カットか末尾の修正指示欄に入力できます。

全カットを上からスクロールして、画像・字幕・読み・音声を見直してください。修正指示をまとめて反映し、変更した読みを確認して必要な音声を作り直します。修正後の再確認が終わったら、最後のボタンで全カットを一括確認します。

送信・反映すると指示と台本をGoogleへ送り、API料金が発生する場合があります。画像変更が必要なカットのみ画像も送信・再生成します。変更のない画像・音声は再利用します。本文・読みが変わったカットは、読みの確認後に音声を再生成します。下書き保存と最後の確認ではAPIを呼びません。
