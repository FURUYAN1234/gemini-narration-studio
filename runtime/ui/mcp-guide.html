ナレーション動画メーカーのMCP導入

  1. Windowsで start_narration_studio.bat を起動します。初回に必要なNode.js、ライブラリ、レンダー用ブラウザーを用意します。
  2. 利用するAIのMCP設定に、コマンド node と引数 展開先の絶対パス/mcp/server.mjs を登録します。ローカルスタジオの既定ポートは6181です。別ポートを使う場合は --port とポート番号を追加します。
  3. 実行チャットの内蔵ブラウザーにスタジオを表示し、画面上部で「MCP接続を許可」を押します。AIが studio_project で制作を確認すると「MCP 接続済み」になります。
  4. 操作を手動に戻すときは画面上部の「停止して手動に戻る」を押します。別の制作を開いた場合は再度許可してください。

できること

  • studio_project で制作・素材・録画・書き出し状況を確認します。
  • studio_record_demo でローカルデモの操作を録画します。操作名と時刻をGeminiへ送ることに同意した場合、studio_edit_recording でカット案を作れます。
  • studio_render_promo で画像・録画にカット範囲・字幕・任意の音声を指定して短い紹介MP4を作ります。BGMと切り替え音を使わない場合は soundEnabled: false を指定します。完成動画は制作画面の下部で再生できます。
  • studio_render_preview で作成済みの音声と素材から確認用のナレーション動画を作ります。

紹介動画にはGemini APIキーは要りません。音声を新規に作る場合は、スタジオのAPI設定と読み・音声の確認手順を使います。
