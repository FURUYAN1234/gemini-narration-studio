ナレーション動画メーカーのMCP導入

  1. Windowsで start_narration_studio.bat を起動します。初回に必要なNode.js、ライブラリ、レンダー用ブラウザーを用意します。
  2. 利用するAIのMCP設定に、コマンド node と引数 展開先の絶対パス/mcp/server.mjs を登録します。ローカルスタジオの既定ポートは6181です。別ポートを使う場合は --port とポート番号を追加します。
  3. 実行チャットの内蔵ブラウザーにスタジオを表示し、画面上部で「MCP接続を許可」を押します。AIが studio_project で制作を確認すると「MCP 接続済み」になります。
  4. 操作を手動に戻すときは画面上部の「停止して手動に戻る」を押します。別の制作を開いた場合は再度許可してください。

できること

  • studio_project で制作・素材・録画・書き出し状況を確認します。
  • studio_record_demo で、このPCで動くブラウザー版アプリ（http://127.0.0.1:ポート/）を自動操作して録画します。操作名と時刻をGeminiへ送ることに同意した場合、studio_edit_recording でカット案を作れます。
  • studio_render_promo で画像・録画にカット範囲と字幕を指定して紹介MP4を作ります。本文音声を narration に指定するときは、タイトルを読んだ別音声を titleCall に指定します。タイトル表示とその音声の後に本文が始まります。意図して省く場合は openingTitleRequired: false を指定します。BGMと切り替え音を使わない場合は soundEnabled: false を指定します。完成動画は制作画面の下部で再生できます。
  • studio_render_preview で作成済みの音声と素材から確認用のナレーション動画を作ります。

紹介動画のHyperFrames書き出し

Windowsのアプリフォルダーで start_narration_studio.bat --install-hyperframes --setup-only を実行します。同じ版が導入済みなら再利用します。導入後はスタジオを起動し直すと、紹介動画の「自動」でHyperFramesが選ばれます。

studio_render_promo の renderer は auto（省略時）、hyperframes、remotion から選べます。HyperFramesではカットごとに focus（映像枠内の百分率の位置と大きさ、ラベル）、steps（2〜4件）、comparison（ラベルと値の2組）を渡せます。演出を省略すると入力に合う表示を選び、操作録画ではカット内の操作名と時刻を手順の表示に使えます。静止画は frames でフレーム単位の長さを指定でき、録画は holdFrames で末尾の画を保持できます（30 fps）。

デスクトップ画面・Windowsアプリの操作動画

デスクトップ画面やWindowsアプリの操作も、画面録画を取り込めば、接続したMCPでカット編集・字幕追加・MP4書き出しができます。AIにWindowsアプリを操作させる場合はCodexのComputer Useを使い、映像は画面録画ツールで収録します。

  1. Computer Useが未導入の場合は、Windows版のCodexで「プラグイン」を開き、Computer Use を検索してインストールします。制作チャットで @Computer Use を選び、録画対象のアプリを指定します。プラグインの提供状況は利用プランや組織の設定によって異なります。プラグイン一覧を開く ／ OpenAI公式のプラグイン導入手順
  2. 画面の録画を開始し、デモを実行します。Windows 11では Snipping Tool の Windows＋Shift＋R で録画範囲を選べます。Computer Useを使えない場合は手動操作で録画できます。Microsoft公式の画面録画手順
  3. 保存したMP4を「素材・台本」に追加し、MCPでカット範囲と字幕を指定して紹介動画を書き出します。通常のナレーション制作ではMP4・WebMを取り込み、③でカットに割り当てられます。

紹介動画にはGemini APIキーは要りません。音声を新規に作る場合は、スタジオのAPI設定と読み・音声の確認手順を使います。
