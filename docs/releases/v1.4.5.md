# Narrated Video Maker v1.4.5 / ナレーション動画メーカー v1.4.5

## Changes / 更新内容

- New productions enable an opening title by default. For an app explainer, show the official app name and read it aloud before the first explanation cut. / 新規制作では冒頭タイトルが初期状態で有効です。アプリ紹介では、正式名を表示し、最初の発話で読み上げてから説明に進みます。
- When the opening is required, the app checks that its title and reading exist before rendering. The same check applies when reopening a production with that setting. / 冒頭タイトルを有効にした制作では、タイトルと読みが揃ってから動画を書き出します。再開した制作でも同じ設定を使います。
- Short promos play a separate title audio file before the body when narration is present. The same default applies in the form and MCP. / 短尺紹介の本文にナレーションを付ける場合、手入力フォームとMCPの両方で冒頭タイトルの読み上げを既定にしました。
- The operation manual and API setup guide are updated for v1.4.5. / 操作マニュアルとAPI設定ガイドをv1.4.5に更新しました。
