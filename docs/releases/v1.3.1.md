# Narrated Video Maker v1.3.1 / ナレーション動画メーカー v1.3.1

## English

Source-based script planning can now choose comparison cards, ordered steps, highlighted numbers and bar charts for individual cuts. New productions enable these explanatory scenes by default. Cut previews show the selected content, and the scene switch changes rendering without generating new audio or images.

Labels, values and source quotations are checked against the current narration before rendering; charts require matching units and valid numbers. Reveals follow the existing subtitle timing estimate. Existing productions keep their saved settings. No OpenMontage code or new runtime dependency is bundled.

## 日本語

参考資料から台本を作る際に、内容に応じて比較カード・手順・数字強調・棒グラフを選べるようになりました。新規制作では「内容に合わせた図解を使う」が有効です。各カットで図解の内容を確認でき、表示の切り替えだけでは音声や画像を再生成しません。

図解の見出し・数値・引用箇所を現在の台本と照合し、棒グラフでは単位と数値も確認します。図解は既存の字幕タイミング推定に合わせて展開します。保存済みの制作は以前の設定を保持します。OpenMontageのコードや追加の実行環境は同梱していません。
