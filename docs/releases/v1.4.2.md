# Narrated Video Maker v1.4.2 / ナレーション動画メーカー v1.4.2

## Changes / 更新内容

- AI direction uses the subject and each cut’s role to choose the palette, slide layout, and transitions. / 題材とカットの役割に合わせて、配色・スライドの構図・画面切り替えを選びます。
- Videos can use original illustrations generated for the script or play selected excerpts from an imported reference video. / 台本に合わせて挿絵を生成できます。取り込んだ参照動画は必要な区間をカット内で再生できます。
- Use a narrator recommended for the script, or choose the voice yourself. / 台本に合わせたAIの声の提案と手動での声選びを使えます。
- If the AI returns an invalid optional diagram, the app keeps the valid parts of the scene plan. / 任意の図解に不正なデータがあった場合も、カット案の有効な部分を保持します。

## Verification / 検証

- The tone-editing demo exported a 31.275-second video with the selected 8.5-second screen-recording excerpt and Charon narration. / トーン操作の解説では、指定した画面録画の8.5秒区間とCharonの声を入れた31.275秒のMP4を書き出しました。
- The autumn forest example exported a 34.603-second video with three generated illustrations, Gacrux narration, and generated music. / 秋の森の題材では、生成した挿絵3枚とGacruxの声、生成BGMを使った34.603秒のMP4を書き出しました。
