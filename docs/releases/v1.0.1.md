# Gemini Narration Studio v1.0.1

## English

Keep custom voice preview caches beside durable production data so backup includes them. Distribution checks reject private data and installed dependencies even when they are forcibly added to Git. The batch launcher and Codex share the same local studio.

## 日本語

追加で作成する音声サンプルも制作データと同じ保存先に置き、バックアップ対象に含めます。個人の制作データやインストール済み依存ファイルが強制的にGitへ追加されていても、配布前のチェックで拒否します。起動バッチとCodexは同じローカルスタジオを利用します。
