# Gemini Narration Studio v1.2.4

## English

Adding materials after editing the script keeps the draft usable for adoption. The save baseline advances only when the same project's script and other saved inputs remain unchanged, so another screen's edits still cannot be overwritten.

Includes the word-aware heading wrapping and the image approval, full narration and MP4/M4A export workflow. Distribution remains private with Pages disabled.

## 日本語

台本を入力してから素材を追加しても、入力を保持して台本を採用できるよう修正しました。同じ制作の台本や他の保存内容が変わっていない場合だけ保存基準を更新し、別画面の編集を上書きすることは引き続き防ぎます。

語の区切りでの見出し改行、画像案の承認、一本の全文音声、MP4と単独音声M4Aの出力も含みます。非公開配布とPages無効を維持します。
