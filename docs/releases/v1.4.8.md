# Narrated Video Maker v1.4.8 / ナレーション動画メーカー v1.4.8

- New narrated videos leave one second between cuts by default. At that setting, a distinct next scene appears about 0.4 seconds before its narration and captions. / 新規のナレーション動画では、カット間の標準を1.0秒にしました。別の場面に切り替わるときは、次の声と字幕より約0.4秒先に画面が切り替わります。
- Adjust the pause in Step 3 and render again using the existing narration and background music. Contiguous excerpts of the same recording keep their original cut timing. / 間の長さは③で調整し、作成済みの音声とBGMで書き出し直せます。同じ録画から切り出した連続区間は元の切り替え位置を保ちます。
- Updated the Windows operation and API guides for this release. / Windows版の操作ガイドとAPI設定ガイドを更新しました。
