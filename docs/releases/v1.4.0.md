# Narrated Video Maker v1.4.0 / ナレーション動画メーカー v1.4.0

## 日本語

- Windowsの起動バッチが初回に録画用Chromiumを準備します。紹介動画フォームから、別のローカルアプリをサンプル操作で録画できます。
- 録画と静止画を最大6カットに編集し、見出し・字幕・任意のナレーション音声とBGMを付けてMP4に保存できます。
- Geminiで操作名と時刻からカット案を作成できます。制作スキルは、許可したMCP接続で録画から書き出しまで実行できます。

## English

- The Windows launcher prepares a pinned Chromium for recording a separate local web app.
- Edit up to six clips and screenshots and export an MP4 with captions, optional narration and music.
- Ask Gemini for a cut proposal by opting in to share operation names and timings. The production skill can orchestrate recording and export over the approved MCP connection.

Recording workflow inspired by [autoRecording](https://github.com/OrrrGE/autoRecording). Implementation uses [Playwright](https://github.com/microsoft/playwright).
