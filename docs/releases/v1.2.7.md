# Gemini Narration Studio v1.2.7

## English

Save, remove, clear and revise actions now have visible button boundaries. Step navigation that saves edits uses buttons, the save action opens directly, and the unused manual-cut form is removed. Image replacement identifies the entire drop area and explains when API registration is required.

AI script generation now supplies and validates the title reading, retains it with the draft and fills the reading-review field without another AI request. User edits are preserved. Bounded diagnostic failure codes survive a subsequent successful generation.

Validation includes regression tests and one real URL-only generation: the first click produced a script, five images and the title reading. The previously reported first-click no-op was not reproduced, so this release does not claim its root cause is resolved. The template-preview versus animated-video layout mismatch remains a known issue.

## 日本語

保存・削除・クリア・修正などの操作を、枠のあるボタンへ統一しました。編集を保存するSTEP移動もボタンにし、途中保存は直接実行できるようにしました。不要な手動カット追加欄を削除し、画像差し替えはドロップできる枠全体を明記、APIキー未設定時は理由を表示します。

AIの台本生成でタイトルの読みも取得・検証し、台本とともに保存して読み確認欄へ入れます。追加のAI操作は不要で、ユーザーが編集した読みは保持します。生成失敗の診断コードは、次の生成が成功しても件数を制限して残します。

回帰検査に加え、URLだけの実API検証で、初回クリックから台本・画像5枚・タイトルの読みの生成を確認しました。以前の初回クリック無反応は再現せず、原因解消済みとは扱いません。テンプレート見本と動き付き動画の配置が異なる問題は未解決です。
