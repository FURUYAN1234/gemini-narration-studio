# Gemini Narration Studio v1.0.0

## English

Private standalone Windows distribution with a batch launcher and first-run renderer setup. Includes 180 voice/pitch preview samples, script and pronunciation review, cut correction, and local subtitled MP4 creation. Codex and direct local launch share durable production data outside the application folder.

## 日本語

起動バッチと初回の動画処理セットアップを備えた、Windows用の非公開配布版です。180種類の声・ピッチの試聴、台本と読みの確認、カットの修正、字幕付きMP4の作成に対応します。Codexからの呼び出しと直接のローカル起動で、アプリ本体とは別に保存した制作データを共用します。
