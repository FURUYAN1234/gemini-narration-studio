# Gemini Narration Studio v1.1.0

## English

Build narrated motion videos from supplied materials. Gemini proposes a source-grounded script, title, voice and focal image treatment; users review readings before speech synthesis. Relevant supplied images can be mixed with generated images. Optional Lyria BGM follows the narration duration, ducks under speech and fades at the end. Opening title calls and lower-right ending credits retain the original creation year across revisions.

The Windows batch installs missing Node.js/npm from a checksum-verified official portable ZIP without administrator privileges. Existing supported runtimes are reused; pinned rendering dependencies and the rendering browser are prepared when missing. The interface prioritizes existing BGM and adds a bottom new-video action with unsaved-work guards. README, offline article draft and publication checklist describe the workflow and limits.

Private repository and Release distribution only; GitHub Pages remains disabled. Personal production data and API keys are excluded. No full backup, public article or social post is part of this release.

## 日本語

画像・TXT・参考本文・公開URLなどから構成・台本・タイトル・声・画像の注目位置を提案し、読みを確認してからナレーション付き動画を作れるようにしました。関連する提供画像を選び、不足分を生成画像で補えます。LyriaのBGMは音声尺に合わせ、ナレーション中に減音し、最後をフェードアウトします。冒頭タイトルコールと右下EDを追加し、作者マークの作成年は修正版でも維持します。

起動バッチは、Node.js/npmが不足している場合に公式の検証済みZIPを利用者専用フォルダへ自動導入します。既存環境は再利用し、動画処理ライブラリと描画ブラウザも不足時に準備します。作成済みBGMを先に表示し、最下部から既存作品を残して新規作成へ戻れます。README・note用原稿・公開準備文書を現行機能に揃えました。

非公開GitHubとReleaseでの配布を維持し、Pagesは無効です。個人の制作物とAPIキーは同梱しません。フルバックアップ、note一般公開、SNS投稿は今回実行しません。
