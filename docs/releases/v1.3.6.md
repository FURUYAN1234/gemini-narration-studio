# Narrated Video Maker / ナレーション動画メーカー v1.3.6

## Changes / 更新内容

- Turn imported screenshots into a short MP4 with animated transitions, locally generated music and sound effects. Playback and download appear below the production workflow. / 取り込んだ実画面から、場面の切り替えとローカル生成のBGM・効果音を付けた短いMP4を作れます。再生と保存は制作画面の下部にまとめました。
- Connect an MCP client to the current project after granting access in the studio. The client can inspect materials and progress, render a product demo, and render a preview from prepared narration. The studio includes an MCP guide and a downloadable production skill. / 制作画面で接続を許可すると、MCPから現在の制作と素材・進捗を確認し、紹介動画や準備済みナレーションの確認版を書き出せます。MCP導入ガイドと制作スキルを同梱しました。
- The legacy end watermark is enabled by default and can be turned off. Production credits remain on the end card. / 従来の末尾透かしは初期値オンで、必要に応じてオフにできます。末尾には実際に使用した制作環境が残ります。
- Improved spacing in the upper toolbar, API settings, and export forms at wide and narrow widths. / 上部のツールバー、API設定、書き出しフォームの間隔を見直し、狭い画面でもGeminiの文字が収まるようにしました。

## Verified sample / 確認した作例

- The 83-second, 1080p reference video uses six Gemini TTS cuts, Lyria music, and original Hairline artwork. The studio created the audio and video, and an MCP preview render reused the prepared audio after a visual edit. / 83秒の1080p作例は、Gemini TTSの6カット、LyriaのBGM、Hairlineで作成した図解を使用しています。通常画面で作成し、映像を差し替えた後はMCPから既存音源を使って再書き出ししました。

## Download / 入手

Save and extract **Source code (zip)** from Assets, then run `start_narration_studio.bat` on Windows. / Assetsの **Source code (zip)** を保存・展開し、Windowsで `start_narration_studio.bat` を起動してください。
