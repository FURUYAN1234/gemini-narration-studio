# Narrated Video Maker v1.5.1 / ナレーション動画メーカー v1.5.1

- The production skill specifies Gemini TTS for the opening title and body. Record the model and voice used. If Gemini is unavailable, pause speech generation and explain the reason. Use a different voice source only when the requester explicitly specifies it for the video. / 制作スキルでは冒頭タイトルと本文にGemini TTSを使い、モデルと声名を記録します。接続できない場合は音声生成を保留して理由を伝え、依頼者の明示指定がある場合に限り別の音声を使います。
- Check captions against the final speech and screen changes in the exported MP4. When publishing, confirm that viewers can play the same video that was reviewed, and verify the listed duration and links. / 完成MP4で発話の開始・終了、字幕、画面を照合します。公開後は確認した動画と一致すること、掲載した尺とリンクを確かめます。
- The production skill ZIP, setup instructions, bilingual README and both Japanese PDF guides reflect this workflow. The v1.5.0 walkthrough remains available and shows the same app workflow. / 制作スキルZIP、導入案内、日英README、操作・API設定PDFに新しい確認手順を反映しました。既存のv1.5.0全体紹介で操作の流れを確認できます。
