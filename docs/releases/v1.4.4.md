# Narrated Video Maker v1.4.4 / ナレーション動画メーカー v1.4.4

## Changes / 更新内容

- After confirming the reading and voice, click “Create narration audio only” to start Gemini TTS immediately. The number of requests and possible charges are shown next to the button. / 読みと声を確定したら、「ナレーション音声だけ作成」の一度の操作でGemini TTSを開始します。APIの実行回数と料金の案内はボタンのそばに表示します。
- Enable per-project audio review to check synthesized narration for clear pronunciation or delivery problems. The app can try one equivalent rephrasing and checks that take again before using it. If the issue remains or the finding is uncertain, listen to the original cut and decide how to proceed. / 制作ごとに音声の自動検査を選べます。明確な誤読や発声の異常があれば、同じ意味の読みを1回まで再合成し、再検査に通った音声を使います。判断が難しい箇所や直らなかった箇所は元の音声を試聴して採用・修正を選べます。

## Verification / 検証

- One normal click produced an Aoede take through Gemini 3.8 Flash TTS and checked it with the Gemini audio review API. Regression tests covered a successful repair, an inconclusive finding, a rejected rewrite, and cancellation. / 一度の操作でGemini 3.8 Flash TTSのAoedeを合成し、Geminiの音声検査まで実行しました。修正成功、判定保留、言い換えの不採用、中止後の音声保持は回帰テストで確認しました。
