# Gemini Narration Studio v1.2.5

## English

AI image preparation now produces actual images before adoption. Review and adopt each image without another API call, regenerate only a chosen cut, or replace it with a local file. Pending candidates survive restart and reading or voice changes; they cannot be silently adopted or bypass final review.

Automatic theme hides manual instructions and excludes their old values from requests. Script output stays below its inputs, manual direction stays expanded when automatic direction is off, and color previews follow the renderer palette. Removed material diagnostics and ending-credit forms; exports retain the established URL, author and creation-year watermark. Existing productions and completed media are preserved. Private distribution, with Pages disabled.

## 日本語

AIが実画像を準備してから、カットごとに確認・採用する流れへ修正しました。採用ではAPIを呼ばず、気になるカットだけ再生成・ファイル差し替えできます。未採用候補は再起動や読み・声の変更後も保持し、承認なしの採用や最終確定を防ぎます。

テーマをAIに任せると手動指示欄を隠し、残った旧入力も送信しません。台本結果を入力欄の下へ集約し、自動演出OFFでは手動調整欄を開いた状態にします。配色の見本も描画側と合わせました。素材診断とエンドクレジットの入力欄を削除し、動画末尾には従来のURL・作者名・作成年のウォーターマークを表示します。既存の制作・完成メディアを保持します。非公開配布・Pages無効を維持します。
