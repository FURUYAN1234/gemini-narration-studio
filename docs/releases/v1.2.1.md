# Gemini Narration Studio v1.2.1

## English

Script creation now separates instructions, explicit generation, editable results and adoption. Reference-only requests are supported; manual entry hides AI controls. Saved drafts, current results and existing audio survive validation and save failures, with stale requests and duplicate submissions rejected.

Improved Gemini JSON response handling retains strict script, pronunciation and source validation. Scene transitions now offer 13 families and 35 shape/direction variants, using adopted artwork and the selected palette. The existing AI planning request can propose transition families and surfaces; local rendering avoids consecutive repetition and protects subtitles. Batch startup checks the running studio's build before reusing it.

The pinned Remotion dependencies are updated to 4.0.534, removing vulnerable ZIP extraction and WebSocket dependencies. The existing distribution preflight now rejects dependency vulnerabilities and unavailable audit results.

Distribution remains a private GitHub Release with Pages disabled. Personal projects and credentials are excluded. Existing completed videos retain their saved credits and media; this release does not rewrite them.

## 日本語

台本作成を、制作指示・明示的な生成・編集可能な結果・採用の流れに整理しました。参考資料だけでも作成でき、手入力ではAI操作を隠します。検証・保存に失敗しても下書き・生成結果・既存音声を保持し、古い入力への応答や重複送信を拒否します。

GeminiのJSON応答処理を改善し、台本・読み・出典の必須検査を維持しました。場面切替は13系統・35種類の形と方向を用意し、採用画像と選択した配色を使い分けます。既存のAI構成作成と同じ送信で切替の種類と表示面を提案でき、描画側で連続使用を避け、字幕を保護します。バッチ起動は実行中のスタジオの構成を照合してから再利用します。

固定したRemotion依存を4.0.534へ更新し、脆弱性のあるZIP展開・WebSocket依存を解消しました。既存の配布前検査で依存の脆弱性と監査不能を拒否します。

非公開GitHub Releaseでの配布とPages無効を維持します。個人の制作物・認証情報は配布しません。既存の完成動画のクレジット・素材は保存した設定を保持し、今回の更新では書き換えません。
