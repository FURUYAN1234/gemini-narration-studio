# Gemini Narration Studio v1.2.0

## English

Choose from twelve video templates, including new broadsheet, gallery, flow and briefing layouts. Each new layout keeps its composition during local motion rendering, reveals points over time and reserves a separate subtitle region. Template selection uses no generation API.

Source planning now proposes each cut's purpose and a shared visual style, displays them for review and applies that style to planned image prompts. Existing reading, audio, asset and final-review controls remain in place. The explanatory-video guidance adapts principles from Hallmark and Director Skills; these repositories are not runtime dependencies.

Verification covers the template and Director regressions, documentation screenshot allowlist and image-signature checks, package audit, four static and four motion frames, and a decoded template-preview MP4. A separate new video was created through the actual studio with one Kore / Gemini 3.8 Flash TTS request, user reading and listening confirmation, final sealing, full media decoding and Downloads hash verification. The new AI source-planning guidance has local regression coverage; it was not exercised with a paid live planning request. The README pairs English and Japanese instructions with three actual app screenshots.

Distribution remains a private GitHub Release with GitHub Pages disabled. Personal production files and credentials are excluded from the release. Full backup and public announcements are separate operations.

## 日本語

動画テンプレートを8種類から12種類に増やし、ニュース紙面・展示ギャラリー・流れ解説・ブリーフィングを追加しました。新しい構成は動きを有効にしても維持され、要点を順に表示します。字幕は専用領域に分けています。テンプレートの比較・選択では生成APIを使いません。

素材からの構成案に、各カットの役割と共通の視覚方針を追加しました。確認画面に表示し、生成予定の画像指示にも反映します。読み・音声・素材・最終確認の既存の制御は維持しています。HallmarkとDirector Skillsの考え方を解説動画向けに取り入れました。両リポジトリの実行環境は不要です。

テンプレート・構成方針の回帰テスト、説明用画像の配布範囲と署名検査、配布監査を用意しました。新テンプレート4種類の静止・動作フレームとプレビューMP4の全デコードを確認しました。別途、実アプリで新しい試作動画を作成し、Kore / Gemini 3.8 Flash TTSを1回使用しました。利用者の読み・試聴確認、最終確定を経て、動画の検査とダウンロード保存先のハッシュ一致を確認しています。新しいAI構成方針は回帰テストで検証済みですが、有料の構成生成APIによる実検証は行っていません。READMEは英日併記にし、実画面3枚を挿入しました。

非公開GitHub Releaseでの配布とPages無効を維持します。個人の制作物・認証情報は配布しません。フルバックアップと一般向け告知は別操作です。
