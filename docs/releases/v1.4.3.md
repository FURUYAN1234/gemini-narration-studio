# Narrated Video Maker v1.4.3 / ナレーション動画メーカー v1.4.3

## Changes / 更新内容

- Install the optional HyperFrames renderer with `start_narration_studio.bat --install-hyperframes --setup-only`. Auto selects it for product demos when installed, and otherwise selects Remotion. / バッチでHyperFramesを追加できます。紹介動画の「自動」は導入済みならHyperFrames、未導入ならRemotionを選びます。
- For MCP product demos, use recorded operation times for step reveals, or specify a focus rectangle, steps, or two comparison entries. Still images support frame-level durations. A recording can hold its final frame. / MCPでは、録画中の操作時刻に合わせた手順表示や、強調枠・手順・比較2項目を指定できます。静止画はフレーム単位で尺を指定でき、録画の末尾は最後の画を保持できます。
- Create narration audio on its own after confirming the reading and voice. Japanese headings, subtitles, and end titles wrap at word boundaries in HyperFrames exports. / 読みと声の確定後に、ナレーション音声だけを作成できます。HyperFrames書き出しでは、日本語の見出し・字幕・末尾タイトルを語のまとまりに合わせて折り返します。

## Verification / 検証

- Tested initial installation and reuse on Windows, then exported a 30.2-second, six-cut 1920×1080 video through MCP. The speech produced by a single Gemini 3.8 Flash TTS request using Kore was matched to the exported audio across all six cuts. / Windowsで初回導入と再利用を確認しました。MCPで1920×1080・全6カット・30.2秒の動画を書き出し、Gemini 3.8 Flash TTSで1回合成したKoreの音声と書き出し後の6カットを波形照合しました。
