# Narrated Video Maker / ナレーション動画メーカー v1.3.0

## English

First public release under the clearer name Narrated Video Maker. Download the source ZIP, extract it and run start_narration_studio.bat on Windows x64; the public website provides installation guidance and does not run the local video backend.

Captions now use balanced, word-aware bounded lines across every template instead of leaving a tiny final verb fragment. BGM is automatic, creation uses one clearly named action, references have optional thumbnail selection, and accumulated production history has been removed. Current production and exported Downloads are preserved during app updates. The existing reviewed reading and completed-video confirmation gates remain.

README and the public guide include current real app screenshots and detailed batch, API, save/resume and troubleshooting instructions. The FURU application terms are included beginning with this release; external API fees and third-party conditions, including Remotion licensing, remain separate.

## 日本語

「ナレーション動画メーカー」の名称で初めて一般公開します。Windows x64でソースZIPを展開し、start_narration_studio.batを起動してください。公開ページは導入案内で、ローカルの動画処理を直接実行するページではありません。

字幕を全テンプレートで単語を考慮した均等な行割りに統一し、語尾だけの短い行を改善しました。BGMは自動で付き、作成ボタンを分かりやすく統一。参照画像は任意のサムネイル選択に変更し、制作履歴を撤去しました。本体更新では現在の制作とダウンロード済みの書き出しを保持し、読みと完成動画の確認手順も維持します。

READMEと公開案内に現行の実画面と、バッチ起動・API・保存と再開・トラブル対応の詳細を掲載。この版からFURU利用条件を添付します。外部API料金とRemotionを含む第三者条件は別途適用されます。
