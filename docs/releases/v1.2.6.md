# Gemini Narration Studio v1.2.6

## English

The script-generation operation now assigns supplied images and generates missing images before presenting its result. The editable script and actual images appear together; individual AI regeneration, local file replacement and removal stay with each image. Adopting the script and images and choosing a voice make no image-generation request.

Image preparation failures retain the new script and completed images. Only the failed cut needs an explicit retry; a partial result cannot be adopted as a completed image set. Request replay does not repeat planning or generation, and cancellation preserves validated work. Existing productions, generated media, fixed watermark, private distribution and disabled Pages are preserved.

## 日本語

台本生成の処理で、提供画像の割り当てと不足画像の生成まで行ってから結果を提示します。編集できる台本と実画像を同じ結果欄へまとめ、個別のAI再生成・ファイル差し替え・削除も各画像に置きました。台本と画像の採用や声選びでは、画像生成APIを呼びません。

画像準備に失敗した場合も、新しい台本と生成できた画像を保持します。失敗したカットだけ明示的に再開でき、未準備の画像を残したまま採用できません。同じ依頼の再送で計画・生成を繰り返さず、中断でも検証済みの内容を保持します。既存の制作・生成物・固定ウォーターマーク・非公開配布・Pages無効を維持します。
