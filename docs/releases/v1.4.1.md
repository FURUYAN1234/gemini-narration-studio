# Narrated Video Maker v1.4.1 / ナレーション動画メーカー v1.4.1

## Changes / 更新内容

- The demo form now identifies built-in automatic recording as a feature for web apps running on this PC. / 紹介動画フォームに、内蔵の自動録画はこのPCで動くブラウザー版アプリ専用だと明記しました。
- The MCP guide explains how to record a Windows desktop app separately, import the MP4, and use MCP to specify cuts and captions and export the video. It also links to the Codex Computer Use setup instructions. / Windowsアプリの画面を別途録画し、MP4を取り込んでMCPで編集・書き出しする手順を、CodexのComputer Use導入案内とともに追加しました。
- You can remove the current BGM from the materials list. The audio file stays on your PC, and videos omit BGM until you re-enable automatic generation. / 使用中のBGMを素材一覧から外せます。元の音声はPCに残り、自動生成を再開するまではBGMなしで動画を作成できます。
