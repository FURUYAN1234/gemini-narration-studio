# Narrated Video Maker v1.4.6 / ナレーション動画メーカー v1.4.6

- Request a visual and voice plan from an existing script in one Gemini call. The app keeps your script and title, and proposes the palette, layout by cut, transitions, and voice in automatic voice mode. / 用意した台本とタイトルを保ったまま、Geminiへの1回の送信で配色、カットごとの配置、切り替え、自動選択時の声と話し方を提案します。
- Keep the selected voice in manual mode and review the proposal before creating audio or video. Editing the script clears its current proposal. / 手動で選んだ声を引き継ぎ、音声や動画の生成前に提案を確認できます。台本を編集すると保存済みの演出提案は外れます。
- The short promo tool uses cut labels and captions to choose backgrounds, entrances, music pacing and cue sounds locally in both renderers. / 短尺紹介では見出しや字幕、操作・比較の場面指定に応じて、両レンダラーの背景、登場の動き、BGMの速さと切り替え音をローカルで調整します。
- Updated the supplied production skill and the Windows operation and API guides. / 同梱の汎用制作スキルと、Windows版の操作・APIガイドを更新しました。
