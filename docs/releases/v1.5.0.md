# Narrated Video Maker v1.5.0 / ナレーション動画メーカー v1.5.0

- Japanese opening brackets stay with the following caption at a sentence boundary. / 文の境目では、日本語の開き括弧と続く操作名や引用を同じ字幕に表示します。
- The production skill now covers full app walkthroughs, recording real actions and results, synchronizing the voice, captions and screen, and checking the ending. / 制作スキルに、アプリ全体の実録画、発話と字幕と画面の同期、動画の目的に合った締めの確認手順を追加しました。
