# Narrated Video Maker v1.4.7 / ナレーション動画メーカー v1.4.7

- When automatic direction is enabled, advancing from the script requests a Gemini plan if the current draft has none. The plan can choose a layout for each cut and leave some transitions as straight cuts. / 自動演出が有効な場合、今の台本に提案がなければ、声選びへ進むときにGeminiが演出を提案します。カットごとの配置を選び、演出が必要ない箇所は通常のカットにできます。
- Repeated consecutive transition effects use a substitute suited to the next cut. Removed the animated orbit behind slides and the fixed alternating layout in short promos. / 同じ切り替えが連続するときは、次のカットに合う別の効果に切り替えます。スライドの軌道アニメーションと、短尺紹介の機械的な左右交互配置を外しました。
- Short promos use the same direction in Remotion and HyperFrames. Optional sound effects follow the selected transitions. The background-music option starts on and generates a score from the script and cut timing using Lyria 3.5. / 短尺紹介ではRemotionとHyperFramesで同じ演出案を使います。切り替え音は任意です。BGMは初期状態でオンで、台本とカットの尺を基にLyria 3.5で作曲します。
- The end card lists the tools used and displays optional author credits from the project. HyperFrames keeps the project title on the opening card. / 末尾には使った制作環境と、登録した場合だけ作者クレジットを表示します。HyperFramesのタイトル表示は冒頭にまとめました。
- The bundled production skill covers matching illustrations to each cut, rendering subtitles once, and reviewing the finished MP4 cut by cut. / 同梱の制作スキルにカットごとの素材、字幕の一系統化、完成MP4の全編確認を反映しました。
- The short promo form, MCP guide, distributed production skill, and operation and API PDFs describe the updated flow. / 短尺紹介フォーム、MCP導入ガイド、配布用制作スキル、操作・APIのPDFを更新しました。
