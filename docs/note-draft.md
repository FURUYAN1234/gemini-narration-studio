# 素材を入れて、声と動きのある動画へ。Gemini ナレーション・スタジオを作りました

画像やメモを集めたあと、「これを動画にするには、まず何から手を付ければいいんだろう」と止まることがあります。

Gemini ナレーション・スタジオは、素材を先に入れ、AIに構成と台本を考えてもらい、声・絵・音楽を確認して一本の動画にするWindows用ローカルアプリです。背景や文字、画像を動かす演出に加え、タイトルコールとエンドクレジットも付けられます。v1.2.0ではテンプレートを12種類に増やし、ニュース紙面・展示ギャラリー・流れ解説・ブリーフィングを追加しました。素材からの構成案では、各カットの役割と共通の配色・外見の方針も確認できます。

## 最初は、素材をまとめて入れる

画像やUTF-8のTXTファイル、参考文章、公開URLを追加し、どんな動画にしたいかを書きます。PDF・音声・動画も資料として追加できます。ファイルは合計12MB・20件まで、URLは10件までです。

「素材から構成・台本を作る」を押すと、Geminiが実際の資料を読み、字幕・ひらがなの読み・カットの見出し・画像の使い方を提案します。資料の要約とカットごとの出典を見ながら確認できます。ログインが必要なURLや、リンク先を次々にたどる収集には対応していません。

タイトルとナレーションの声はAIに任せることも、自分で決めることもできます。AIが考えたタイトルを手で直しても構いません。

## 提供画像を全部使う必要はありません

構成に合う画像だけを選び、足りない絵はGeminiで追加生成できます。「提供素材のみ」も選べます。画像を替えただけなら、変更していないナレーションを作り直す必要はありません。

画面の演出は、画像への寄りや奥行き、大きな文字の展開、線と要点の段階表示などから選べます。画像・背景・文字を別々に動かす仕組みです。画像の人物が新しい演技をする動画生成とは異なり、素材を生かして見せ方を組み立てます。

## 読みを確認してから、声にする

漢字や英字をそのまま読ませて意図と違う発音になるのを減らすため、字幕とひらがなの読みを並べて確認します。読みを確定してからGeminiの音声を作り、実際の音声を聴いて確認します。

30種類の声、2モデル、3段階の話し方の違いを比べる180種類の標準サンプルを同梱しています。サンプル比較だけなら追加の生成APIは使いません。ピッチは話し方への指示で、音程を半音単位で固定する機能ではありません。

## BGMと、一呼吸の間

必要なら、台本と音声の長さをもとにLyriaでBGMを作れます。曲調は指定しても、AIに任せても大丈夫です。歌のない曲を指示しますが、歌声の混入や雰囲気は試聴して確認してください。

動画ではナレーション中に音楽を下げ、最後をフェードアウトします。短い曲はつなぎ、長い曲は動画の長さで終わるよう調整します。音量とカット間の余白も変更でき、新規動画では話し終わりに0.8秒の間を置きます。

## タイトルからEDまで

冒頭にタイトルとタイトルコールを付け、最後はシステム名・URL・作者マークを右下へ控えめに表示できます。作者マークは「@作成年/作者名」。作成年は制作データに保存されるので、翌年に修正版を書き出しても勝手に変わりません。

全カットの画像・字幕・読み・音声・BGMを確認し、最後にローカルで字幕付きMP4を作ります。完成動画はWindowsのダウンロードフォルダへ保存されます。作り直す場合は修正版を作成し、前の完成動画を残します。

## 起動はバッチをダブルクリック

[GitHubのRelease](https://github.com/FURUYAN1234/gemini-narration-studio/releases/latest)からSource code (zip)をダウンロードし、すべて展開して `start_narration_studio.bat` をダブルクリックします。

Windows x64向けです。初回はインターネット接続が必要で、Node.js/npmがなければ公式の検証済みファイルを利用者専用フォルダへ導入します。動画処理ライブラリと描画ブラウザも不足時に準備します。GitやPythonを別途入れる必要はありません。

起動後、Googleを使う前に画面上部でGemini APIキーを入力します。キーはアプリ起動中だけ保持し、ファイルには保存しません。終了・再起動後は再入力してください。

## 使う前に知っておいてほしいこと

素材解析・文章修正・音声・画像・BGM生成はGoogle APIを使い、料金が発生する場合があります。素材は必要な処理のためGoogleへ送信されます。ローカルアプリだから全処理がオフライン、という意味ではありません。使用するモデルやBGM機能を利用できるキーが必要です。

素材の利用権限や個人情報を確認してから入力してください。AIの提案が正しいか、画像と説明が合っているか、読みが自然かは最終確認が必要です。外部APIが失敗したときに自動で再課金する作りにはしていません。

制作データはアプリ本体と別のフォルダに保存し、配布ZIPには個人の台本・画像・音声・動画を含めません。利用するライブラリの条件は[READMEと第三者コンポーネントの案内](https://github.com/FURUYAN1234/gemini-narration-studio)から確認できます。
