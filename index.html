ナレーション動画メーカー

素材と台本から、声・字幕・BGM付きの16:9動画を作成します。アプリ無料・ソースコード公開。生成APIの利用料は別途必要です。

最新版をダウンロード

このページはダウンロードと導入案内です。
動画制作には、Windows上で付属バッチを起動してください。公開ページだけでは動画を生成できません。Gitをインストールする必要はありません。

短い紹介動画とMCP連携

画面や録画から短い紹介動画をPC上で書き出せます。見出しや字幕、場面の指定に応じて背景・動き・BGM・切り替え音を調整します。制作画面から演出やBGMを提案させる場合はGemini APIキーを使います。MCPで演出を指定し、自動BGMをオフにすれば、APIキーなしで書き出せます。制作画面の「MCP導入ガイド」と「制作スキルを取得」から、対応AIに接続し、素材の確認や書き出しに進めます。

従来の透かしは画面でオフにできます。動画の末尾には使用した制作環境が表示されます。

Windowsで通常起動すると、紹介動画用のHyperFramesと専用FFmpegを自動で準備します。展開したZIPではバッチをダブルクリックし、Gitで取得した場合は npm start でも起動できます。「書き出し方式」の「自動」は、準備済みならHyperFrames、準備に失敗したときはRemotionを使います。通信や書き込み権限を確認し、再起動すると準備を再試行できます。操作録画に記録された操作名と時刻から手順を表示でき、MCPから強調枠や比較図も指定できます。

声と図解で、説明を分かりやすく

写真や参考文章から、商品紹介・活動報告・学習用の16:9動画を作れます。資料からAIで台本を作る際、内容に合う図解を選びます。

  • 比較：二つの特徴を並べて見せます。
  • 手順：説明の順番に合わせて項目を表示します。
  • 数字強調：大切な数値を大きく見せます。
  • 棒グラフ：同じ単位の数値を長さで比較します。

新しく作るときは「内容に合わせた図解を使う（おすすめ）」がONです。カットごとのプレビューで図解・字幕・読みを確認してください。図解だけなら画像は任意です。OFFへの切り替えだけでは生成APIを呼びません。文字や数値は字幕と照合しますが、資料の事実確認は利用者が行います。表示タイミングは推定です。

ダウンロードから起動まで

  1. 上のダウンロードを開き、Assets欄のSource code (zip)を保存します。
  2. ダウンロードしたZIPを右クリックしてすべて展開します。ZIP内のまま実行しないでください。
  3. 展開フォルダーの中で、package.jsonと同じ場所にあるstart_narration_studio.batをダブルクリックします。
  4. 黒いウィンドウで不足するNode.js、動画処理ライブラリ、描画ブラウザーの準備が終わるまで待ちます。
  5. アプリがブラウザーに開きます。開かない場合は、READY表示後にhttp://127.0.0.1:6181/を開きます。

Windows 10/11のx64版が対象です。初回準備には通信と空き容量が必要です。書き込み可能な場所へ展開し、利用中は黒いウィンドウを開いたままにしてください。終了は処理完了後にCtrl+Cです。

APIを準備する

Google AI Studioでご自身のGemini APIキーを用意し、アプリ上部のAPI欄へ登録します。キーは起動中のローカルサーバーのメモリだけで保持します。終了・再起動後には再入力してください。詳しくはGoogle公式のキー案内をご覧ください。

動画を作る流れ

  1. 画像や参考本文、公開URLなどを入れて台本を用意します。
  2. 用意した台本でも、本文とタイトルを保ったまま、背景・カットの配置・切り替えと声の提案を頼めます。台本を取り込んだら声とカットを確認します。
  3. 各カットの絵・字幕・読みを確認し、全文の読みを確定します。
  4. 動画を作成で、必要な音声とBGMを自動で準備して動画を作ります。
  5. 完成動画を再生して確認します。MP4とM4AはWindowsのダウンロードへ保存されます。

映像演出は静止画と文字を動かす方式です。人物の新しい演技を生成する機能ではありません。掲載台本は操作例です。

現在の制作を再開するには

通常のバッチ起動で、保存済みの制作を続きから開きます。明示的に再開する場合は、展開したフォルダーで start_narration_studio.bat --resume も使えます。書き出した動画・音声はダウンロードに残ります。
